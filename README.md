# 卓球ラリーシミュレーター

サーブ・レシーブの面の向きやスイングを数値で組み立てて、回転や弾道がどう変わるかを確かめる、ブラウザで動く物理シミュレーターです。

## 使い方

### 1. ダウンロードする

1. このページ上部の緑色の「**Code**」ボタンをクリック
2. 「**Download ZIP**」を選択してダウンロード
3. ダウンロードしたZIPファイルを展開（右クリック →「すべて展開」など）

### 2. 起動する

展開してできたフォルダの中にある `卓球ラリーシミュレーター.html` を、ブラウザ（Chrome / Edge 推奨）でそのまま開くだけで動きます。インストールは不要です。

詳しい操作方法は同梱の `卓球ラリーシミュレーター ブラウザ版マニュアル.html` を参照してください。

## フォルダ構成

- `卓球ラリーシミュレーター.html` — アプリ本体
- `卓球ラリーシミュレーター ブラウザ版マニュアル.html` — 操作マニュアル
- `presets/` — サーブ・レシーブ・ラリーのプリセット集
- `概要動画/` — 紹介動画
